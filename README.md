# 人工智能论文润色SKILL

一个面向 **CVPR、ICCV、ECCV、AAAI、ICML、NeurIPS（NIPS）和 ICLR** 的 Codex 技能。适合手里已有草稿、实验表或审稿意见，想弄清一段为什么读不通、一个实验究竟支持什么，或首页图应该画什么的作者。可以用中文讨论，按原稿语言落笔。

## 怎么改一篇论文

**动笔前，先把挑战和贡献对应起来。** 用一句话说清任务在什么条件下变难，再用一句话写出本文具体做了什么。沿着这层对应去读引言、方法和结果，找到最值得先改的一处。

**每个实验小节回答一个问题。** 按“目的 → 设置 → 结果 → 结论”组织。已经交代过的设置可以略过。结尾解释这些观察给方法设计或使用带来什么认识。

**首页图从论文的重点出发。** 可以只讲一个最突出的挑战或一项贡献，也可以完整展示各项挑战、各项贡献，或把挑战与贡献对应起来。用引言首次引用该图的那句话，检查读者能否在图上找到依据。

## 调用示例

> 用 $ai-paper-writing 审读我的引言。先写出挑战与贡献的对应关系，再指出哪个转折最难跟上，并给一版英文改写。

> 用 $ai-paper-writing 重写消融小节。设置和主实验相同，只补充变化的条件，最后说清这个结果对方法设计意味着什么。

> 用 $ai-paper-writing 帮我选首页图。比较两种方案：只画最突出的挑战，或者用同一案例把挑战和贡献连起来。根据我的引言推荐一版。
